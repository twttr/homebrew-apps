# Homebrew Apps

Homebrew tap for macOS apps by [@twttr](https://github.com/twttr).

## Installation

```bash
brew tap twttr/apps
```

## Available Apps

| App | Description | Install |
|-----|-------------|---------|
| [Mirroreu](https://github.com/twttr/mirroreu) | Enables iPhone Mirroring in EU regions | `brew install --cask mirroreu` |

## Uninstall

```bash
brew uninstall --cask <app>
brew untap twttr/apps
```
